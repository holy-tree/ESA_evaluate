# ESA 异常检测结果评测系统

本系统用于挑战杯项目中 ESA 遥测异常检测结果的评测。上传模型预测的异常区间后，即可查看指标、分析曲线、下载结果并查看排行榜。

## 1. 准备预测文件

支持 **CSV** 和 **JSON** 两种文件格式。

### CSV 格式

每行表示某个通道的一段预测区间：

```csv
channel,starttime,endtime
channel_14,2007-05-11T19:53:45.315Z,2007-05-11T19:53:50.315Z
```

### JSON 格式

使用对象数组，每个对象表示一段预测区间，字段与 CSV 相同，值均为字符串：

```json
[
  {
    "channel": "channel_14",
    "starttime": "2007-05-11T19:53:45.315Z",
    "endtime": "2007-05-11T19:53:50.315Z"
  }
]
```

也支持将数组放在 `predictions` 字段中，即 `{"predictions": [...]}`。多个预测区间分别填写为多个对象，用逗号分隔。

### 填写要求

- `channel`：通道名称，须属于所选 Mission 的目标通道。
- `starttime`、`endtime`：预测开始和结束时间，使用 **UTC**，末尾的 `Z` 表示 UTC 时区。
- 开始时间不能晚于结束时间，所有预测须位于页面设置的评测窗口内。
- 没有预测时，可提交只有表头的 CSV，或内容为 `[]` 的 JSON。

上传文件默认不超过 **5 MiB**。少量预测也可在页面中手动填写。

## 2. 提交评测

1. 在 **评测协议** 中选择 Mission，确认评测窗口，通常使用默认值即可。
2. 进入 **提交预测**，填写用户 ID，建议使用固定的队伍名或模型名。
3. 选择 CSV 或 JSON 上传方式及对应文件，点击 **上传并预览 / 校验**。
4. 如有错误，按提示修改文件后重新上传；校验通过后，返回提交模块，点击 **开始评测**。

评测固定同时考虑 **Anomaly、Rare Event 和 Communication Gap**，无需选择类别。

提交页面提供自检样例下载，可用于熟悉操作；样例由标签构造，**不代表模型性能**。正式提交请使用自己的模型预测结果。

## 3. 查看和使用结果

- **指标结果**：查看总体 F0.5、精确率、召回率及逐通道结果。点击通道可展开检出／漏检明细，也可跳转查看该通道曲线。
- **曲线分析**：红色表示 Anomaly，黄色表示 Rare Event／Communication Gap，绿色表示模型预测。可滚轮缩放、拖动平移，点击事件 ID 定位；点击 **返回默认视图** 恢复评测窗口。
- **下载结果**：点击 **下载评测结果 CSV**，一个文件包含提交信息、总体指标和逐通道指标，可直接用 Excel 打开。
- **排行榜**：成功评测后自动保存成绩。同一用户 ID 保留最高分，同分保留较早提交。

总体指标由各通道独立评分后取平均。F0.5 越高表示综合表现越好；比较模型成绩时，请使用相同的 Mission、数据版本和评测窗口。
