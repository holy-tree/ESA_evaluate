# ESA 异常检测结果评测系统

对 Mission1、Mission2、Mission3 的预测区间**逐通道计算 ESA corrected event-wise F0.5（β=0.5），总体取通道宏平均**。支持手动输入、CSV／JSON 上传、原始曲线与检测区间展示、结果导出。评分只依赖标签；曲线按需读取通道文件，不训练模型。

## 环境依赖

- Python 3.13+、uv。
- Flask、pandas、NumPy、portion、PyYAML；测试使用 pytest。依赖由 `pyproject.toml` 管理，通过 `uv sync` 安装。

## 使用流程

### 1. 准备环境并安装依赖

在项目根目录打开终端，执行：

```powershell
uv --version
uv python install 3.13
uv sync --python 3.13
```

`uv sync` 创建或同步 `.venv`、生成 `uv.lock`，并默认安装测试依赖，无需手动激活环境。

### 2. 配置数据集目录

编辑 **`configs/settings.yaml`**：

```yaml
dataset_root: '../ESA'
```

`dataset_root` 是真实 ESA 数据的根目录。相对路径以**项目根目录**为基准，不受启动终端位置影响；也可以改为绝对路径，例如：

```yaml
dataset_root: 'D:/Projects/pycharm/ESA'
```

更换数据集时只需修改该字段。Windows 路径建议使用正斜杠。代码直接读取 YAML，配置缺失或无效会报错；不再读取 `ESA_DATA_ROOT` 环境变量。使用演示数据时无需配置真实目录。

该目录应包含：

```text
<dataset_root>/
  ESA-Mission1/{labels.csv, anomaly_types.csv, channels.csv}
  ESA-Mission2/{labels.csv, anomaly_types.csv, channels.csv}
  ESA-Mission3/{labels.csv, anomaly_types.csv, channels.csv}
```

真实曲线另需各 Mission 下的 `channels/channel_*.zip`（ESA 原始 pandas 序列）。缺少 ZIP 时仍可评分，图表会显示读取提示；不会用演示曲线替代真实数据。

### 3. 确认 Mission 配置

编辑对应的 `configs/Mission1.json`、`Mission2.json` 或 `Mission3.json`：

| 配置项 | 含义 |
|---|---|
| `sources.real.version` | 数据版本；当前为 `local-unversioned`，有实际版本时请更新 |
| `sources.real.labels` / `anomaly_types` / `channels` | 相对于 YAML 中 `dataset_root` 的文件路径 |
| `sources.real.start` / `end` | 完整观测起止时间，ISO-8601；页面自动填入，使用默认值无需确认。为 `null` 或改用其他窗口时需填写并勾选确认 |
| `sources.real.target_channels`（可选） | 显式目标通道列表；未设置时读取 `channels.csv` 的 `Channel,Target` |
| `sources.real.protocol` | 当前评测协议说明；Mission3 使用自定义评测窗口 |

演示配置位于 `sources.demo`，数据文件路径相对于项目根目录，已提供可直接运行的窗口和标签。

真实配置已填入本地目标通道的实际采样时间边界（Mission1：2000–2013 年；Mission2：2000–2003 年上半年；Mission3：2000–2008 年初），精确值及来源保存在配置的 `start`、`end` 和 `observation_range_source` 中。取全体目标通道最早到最晚时刻的外包范围，并非所有通道共同覆盖的交集，也不表示其间没有缺测；未标注的缺测不额外推断排除。更换数据版本或目标通道时需重新确认窗口。

一次性重新检查时间边界可执行 `uv run python scripts/scan_observation_ranges.py --mission Mission1`（也支持 Mission2、Mission3）。该离线命令逐个读取目标通道 ZIP 并输出各通道时间范围，不自动修改配置；评分本身不读取 ZIP。异常标签边界不用于推断观测范围。

真实标签必需 `ID,Channel,StartTime,EndTime`。类别优先读取标签的 `Category`；缺少时通过 `anomaly_types.csv` 的 `ID,Category` 关联，不猜测类别。`Target` 支持 YES/NO、true/false、1/0；无法识别时需配置 `target_channels`。

### 4. 启动应用

```powershell
uv run app.py
```

打开 **http://127.0.0.1:5000**。先验证流程可直接打开 [Mission1 演示页面](http://127.0.0.1:5000/?mission=Mission1&source=demo)，再切换到 Mission2、Mission3。

### 5. 提交预测并查看结果

1. 选择 Mission、真实 / 演示来源、`Anomaly + Rare Event` 或 `Anomaly only`。
2. 真实配置未设置 `start`、`end` 时，填写完整观测窗口并勾选确认。窗口不会从预测或标签边界推断。
3. 选择一种输入模式：手动添加区间、上传预测 CSV 或上传预测 JSON。演示来源可加载手动示例，也可下载对应 Mission 的 CSV／JSON 模板及示例。
4. CSV／JSON 模式先点击“上传并预览 / 校验”，修正所有错误后点击“开始评测”；预览保留完整文件，无需重新选择。手动模式直接评测。
5. 查看整体分数与事件明细，在原始曲线上查看检测区间，下载结果 JSON 或事件明细 CSV。

修改 Mission、版本、类别、来源或时间窗口后必须重新校验和评分。图表通道筛选只改变显示。

### 原始曲线可视化

- **连续缩放与全历史：**图内滚轮以鼠标时间为中心连续放大／缩小，Shift+滚轮或拖动画布平移；年／月／周／日／时仅为快捷视野。底部全历史时间轴可点击跨年定位、拖动选框及两端缩放，无需逐年翻页。主图保留横向滚动以兼容窄屏。
- **浏览范围独立于评分：**全历史范围来自当前 Mission 已确认的 `start/end`，缺少时仅能使用已确认窗口，不从标签推断。可以浏览本次评分范围之外的数据，灰底标明“本次评分范围外”；分数不会改变。修改评分输入后旧图表失效，重新提交后恢复。
- **降噪显示：**默认远景按时间桶显示中位数趋势、P5–P95 波动带及可选最小／最大值包络，近景恢复原始折线；另可选原始显示、移动平均或高斯核平滑。平滑按实际时间与桶内记录数加权，仅作用于显示，窗口／带宽可填秒数，空值为视窗跨度的 1/50。悬停明确区分原始采样与聚合桶，不将趋势值称为原始值；聚合桶保留记录数、原始极值和分位数。稀少尖峰可能不在中位数／P5–P95 趋势中，需结合极值包络及放大检查。
- **采样间隔与状态：**绘图根据当前窗口中反复出现的采样节奏估计连续性（常见正间隔的高分位数 ×10，阈值至少 1 秒），适应正常变频采样，稀少极长间隔和非有限值处断开；不将该规则作为异常或缺测判定。类别通道保持状态阶梯序列，忽略数值平滑，不把状态编码当作数值大小。
- **多通道：**勾选并“应用通道”；曲线图例悬停／聚焦时浮起加粗、置顶，其余曲线淡化，点击可固定高亮，不移动数据坐标。多通道按通道配色，真实事件在下方标签条展示；单通道可继续按事件 ID 着色。可选参考标准化叠加、原始值叠加或分通道泳道；不同单位不宜直接比较。参考标准化使用每个完整通道至多 20000 个等位置采样的 median/IQR（IQR 为零时用标准差），仅用于绘图，不是模型训练或评分预处理。类别通道独立泳道。
- **预测导航：**“下一预测 J／上一预测 K”导航已选通道的算法报警区间，重叠／相接报警仅为导航合并并保留来源通道，不改变评分。保留当前跨度并平移，区间放不下时扩大；“聚焦当前检查点”适配区间与上下文，“返回上一视图”恢复视窗。橙色描边为当前导航目标，不是真实事件；编辑输入时快捷键不触发。
- **事件标签联动与定位：**悬停／键盘聚焦事件标签时，下方“真实标签”条内该 ID 的全部片段（含多个通道）加厚、描边、投影并置顶，其他事件淡化；不改动片段起止时间，移开恢复原绘制顺序。点击则跳至其起始 UTC 日期，缩小到当天 00:00—次日 00:00（中午居中，数据集边界处裁剪）。跨日或多片段事件按已选通道真实最早起点定位，不使用视窗裁剪后的起点；重复点击不漂移。“返回上一视图”可恢复范围，不改变评分。
- **检测阴影：**`rgba(210,95,95,0.1)` 淡红带为预测区间与有效曲线时间的交集。多通道共享数值轴时对阴影取并集，只填一次；状态泳道分别显示。点／极短区间仅有最小视觉宽度，不改变真实持续时间或分数。
- **缓存与来源：**首次选择真实通道读取 ZIP；多通道 LRU 按缓存数组体积限制为 512 MiB（可用 `ESA_CHART_CACHE_BYTES` 调整，并非进程总内存上限），键包含 Mission、版本、来源、通道及文件修改信息。显示点数按绘图区像素和已选通道分配；原始文件不变。演示曲线来自各 `demo_data/Mission*/telemetry.csv`，明确标为合成演示。

## 输入与输出

### 输入格式

```csv
channel,starttime,endtime
channel_1,2024-01-01T00:00:12Z,2024-01-01T00:00:18Z
```

示例适用于 Mission1 演示配置。真实评测需使用对应目标通道与时间窗口。

JSON 可使用对象数组：

```json
[
  {
    "channel": "channel_1",
    "starttime": "2024-01-01T00:00:12Z",
    "endtime": "2024-01-01T00:00:18Z"
  }
]
```

也接受 `{"predictions": [...]}` 包装形式。每条必需字段均为字符串；不接受用 `null`、数字时间戳或数组代替时间。空预测使用 `[]` 或 `{"predictions": []}`。JSON 模板／示例按对应 Mission 的演示 CSV 动态生成，二者内容保持一致。

- 两种文件均支持 UTF-8 / UTF-8 BOM；字段名忽略大小写及首尾空格，兼容 `Channel,StartTime,EndTime`。缺少必需字段、重复字段名或非法记录会阻止整份文件评分。JSON 不接受注释、尾随逗号、NaN、Infinity。
- 额外字段忽略，预测中的 `ID` 不作为真实事件 ID。Mission、版本、来源和时间范围由网页选择，不从文件猜测；上传文件不覆盖真实标签。一份文件是一次完整实验，手动、CSV、JSON 三种模式不混合。
- 通道须属于当前目标范围，时间须在固定窗口内且开始不晚于结束。CSV 错误按物理行号展示，JSON 按数组记录序号（从 1 开始）展示；JSON 语法错误另含文件行、列。可下载错误 CSV，`line_or_record=0` 表示文件级错误。
- 完全重复记录去重并显示数量；有效记录数包含重复行。预览最多 100 条，评分使用全部有效去重记录。
- 只有合法表头的 CSV、JSON 空数组，或删除所有手动输入行，表示空预测。
- 两种文件共用大小上限 5 MiB、记录上限 100000；环境变量 `ESA_MAX_CSV_BYTES`（保留旧名称，同样限制 JSON）、`ESA_MAX_RECORDS` 可调整。端口通过 `PORT` 调整，默认 5000。切换文件格式、Mission、版本或窗口后，旧预览必须重新校验。

### 时间格式

`2004-12-01T20:42:15.429Z` 表示 **2004 年 12 月 1 日 20:42:15.429，UTC 时间**：

| 部分 | 含义 |
|---|---|
| `2004-12-01` | 年-月-日 |
| `T` | 日期和时间之间的分隔符 |
| `20:42:15` | 24 小时制的时:分:秒 |
| `.429` | 小数秒，429 毫秒；`.429000` 是等值的补零写法 |
| `Z` | UTC 时区，等价于 `+00:00` |

对应北京时间为 `2004-12-02 04:42:15.429`（UTC 加 8 小时）。推荐直接保留数据集的 `Z` 格式；若输入北京时间，应明确带偏移量，例如 `2004-12-02T04:42:15.429+08:00`。不要只改小时却继续保留 `Z`。没有小数秒时可写 `2004-12-01T20:42:15Z`。

### 评分约定

- 时间统一 UTC，无时区输入按 UTC 解释，网页不做本地时区平移。
- 真值为闭区间；普通预测为 `[start,end)`，结束于窗口末端时右闭；`start=end` 为闭点。内部独立点是区间输入适配扩展。
- **每个目标通道独立评分：**只使用该通道的预测和标签，同一 ID 在该通道内组织为区间集合，不填平不连续片段；同通道预测求并集，一次预测仍可命中该通道多个事件。一个通道的预测不能命中另一通道的标签。
- 未选类别仍从**对应通道**的正常时长中排除。合并预测仅在与该通道所有类别标签均不相交时计事件误报；延伸到正常时间的部分仍参与 TNR 修正。其他通道的标签不会保护本通道误报。
- 每通道 `P_corrected = P_event × TNR`；`F0.5 = 1.25 × P_corrected × Recall / (0.25 × P_corrected + Recall)`。
- **总体为算术宏平均：**对每个通道先算完整指标，再对相应指标取均值；不按事件数、时长或预测行数加权。总体 F0.5 直接平均各通道 F0.5，不能用总体精确率／召回率重算；总体修正精确率也不能用总体 P_event × 总体 TNR 代替。
- 评分范围为配置中的全部目标通道，未报警通道也参与，不由图表选择决定。有真实事件但预测为空的通道 F0.5=0；无可评测事件或正常时长为零时，相应未定义指标为 `null`，不填 0 或 1。各总体指标仅平均该指标非 null 的通道，分别导出参与通道数和排除列表；因此分母可能不同。无事件通道的误报仍展示，不因其 F0.5 不适用而隐藏。
- 事件数、检出／漏检数为**事件—通道对合计**，同一 ID 影响两个通道时计两对；另返回去重事件 ID 数。误报区间为各通道合计，时长合计单位是“通道·秒”，这些是统计合计，不是宏平均分数。

这是按需求定义的 `channel-macro-corrected-eventwise-f0.5/v1` 协议，不等同于官方跨通道合并的总体 event-wise 分数；仅每通道的区间评分核心沿用 ESA 定义。`evaluate()` 为应用使用的逐通道／宏平均入口，`evaluate_eventwise()` 保留参考区间核心，供单通道计算与官方交叉验证。

指标参考 [ESA-ADB 官方实现（固定提交 27ecde1）](https://github.com/kplabs-pl/ESA-ADB/blob/27ecde187aa631512cf38a4508474b01ebeb1eda/timeeval/metrics/ESA_ADB_metrics.py)，上游采用 [MIT 许可证](https://github.com/kplabs-pl/ESA-ADB/blob/27ecde187aa631512cf38a4508474b01ebeb1eda/LICENSE)。

### 输出内容

页面展示总体宏平均分、逐通道 F0.5／P_event／TNR／修正精确率／召回率及事件统计。JSON 包含 `aggregation`（各指标参与数与排除通道）、`channel_results`、完整配置及带通道的区间明细；可下载逐通道指标 CSV、逐通道事件明细 CSV 和错误 CSV。

CSV 预览与下载凭据有效期为 1 小时，默认重启后失效；可设置 `ESA_SECRET_KEY` 保持签名密钥固定。

## 验证与真实数据限制

```powershell
uv run pytest -q
uv run python scripts/crosscheck_official.py
uv run python scripts/smoke_real.py
uv run python scripts/smoke_charts.py
uv run python scripts/smoke_chart_explorer.py
```

官方交叉验证需要联网，验证逐通道区间核心（单通道宏平均与其相同），不宣称自定义宏平均等同于官方跨通道合并分数。真实自检预测由标签构造，仅验证管线，不代表模型性能。

当前提供的真实 Mission3 标签存在 18 行反向区间（274–279、472–477、1054–1059 行）。与坏记录两端点包络相交的窗口会阻止评分；完全位于窗口外的坏记录会记录排除说明。真实自检使用 2000-01-01 至 2004-01-01 UTC 的不相交窗口；包含坏记录的范围需先修复标签。
